# Portfolio
 Catalin Dragusanu — Portfolio  Personal portfolio site built with [Astro](https://astro.build) and Tailwind CSS, deployed to Netlify.  Live site: https://portfoliocatalindragusqanu.netlify.app  ## Development  ```bash npm install npm run dev      # http://localhost:4321 npm run build    # static output in dist/ npm test         # markdown lint ```  ## Content  Projects, blog posts, experience and skills live in `src/content/` as markdown/JSON files. Copy `.env.example` to `.env` to override name, contact details and analytics.  ## Deployment  Pushes to `main` build and deploy via GitHub Actions (`.github/workflows/site.yml`). Required repository secrets: `NETLIFY_AUTH_TOKEN`, `NETLIFY_SITE_ID`; optional: `SLACK_WEBHOOK_URL`.
